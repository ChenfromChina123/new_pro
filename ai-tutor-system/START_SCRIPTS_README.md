# 启动脚本说明

本项目提供了多个优化的启动脚本来帮助开发者快速启动服务。

## 脚本列表

### 1. optimized_start.bat
- **功能**: 一键启动前后端服务
- **特点**:
  - 自动检测并释放占用的端口（5000、3000）
  - 自动检查运行环境（Java、Node.js、npm、Maven）
  - 自动安装前端依赖（如需要）
  - 分别启动前后端服务并在新窗口中运行
  - 提供详细的启动日志和状态信息

### 2. optimized_start_backend.bat
- **功能**: 仅启动后端服务
- **特点**:
  - 自动检测并释放5000端口
  - 检查Java和Maven环境
  - 使用优化的JVM参数
  - 提供后端服务专用的日志和监控

### 3. optimized_start_frontend.bat
- **功能**: 仅启动前端服务
- **特点**:
  - 自动检测并释放3000端口
  - 检查Node.js和npm环境
  - 自动安装依赖（如需要）
  - 提供前端服务专用的日志和监控

### 4. build_production.bat
- **功能**: 构建生产版本
- **特点**:
  - 构建混淆后的前端代码
  - 打包后端JAR文件
  - 包含完整的环境检查
  - 提供部署说明

### 5. start_backend.bat (已优化)
- **功能**: 启动后端服务（原始脚本已优化）
- **特点**:
  - 保留原有功能
  - 添加了端口检测和释放
  - 使用更优的JVM参数
  - 改进了日志输出

## 使用说明

1. **开发环境**: 推荐使用 `optimized_start.bat` 一键启动
2. **单独服务**: 根据需要选择对应的专项启动脚本
3. **生产部署**: 使用 `build_production.bat` 构建发布版本
4. **已有服务**: 如果已有一个服务在运行，使用专项启动脚本启动另一个服务

## 端口信息

- **后端端口**: 5000
- **前端端口**: 3000
- **后端API文档**: http://localhost:5000/swagger-ui.html
- **前端访问地址**: http://localhost:3000

## 注意事项

- 脚本会自动检测并终止占用端口的现有进程
- 启动服务的命令行窗口不要关闭，否则服务会停止
- 首次运行可能会较慢，因为需要下载依赖
- 构建生产版本时会包含代码混淆，提升安全性
