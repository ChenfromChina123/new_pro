## 常见问题解答

### 1. 后端依赖管理

**Q**: 后端采用什么管理依赖？maven吗？有什么好处？

**A**: 是的，后端采用 Maven 管理依赖。Maven 的好处包括：
- 依赖管理：自动下载和管理项目依赖，避免版本冲突
- 构建工具：提供统一的构建流程，支持编译、测试、打包等
- 标准化：遵循约定优于配置的原则，提供标准化的项目结构
- 依赖传递：自动处理依赖的依赖，简化依赖管理
- 插件生态：丰富的插件生态，支持各种构建需求
- 多模块支持：适合大型项目的多模块管理
- 中央仓库：访问全球中央仓库，获取开源依赖

### 2. 前端包管理

**Q**: 前端为什么使用npm包管理？

**A**: 前端使用 npm 包管理的原因：
- 前端生态：npm 是前端生态系统的标准包管理器
- 包数量：拥有最多的前端包资源
- 工具集成：与前端构建工具（如 Vite、Webpack）无缝集成
- 版本管理：支持语义化版本控制
- 脚本管理：方便定义和运行前端脚本
- 社区支持：拥有庞大的社区支持和文档

### 3. 项目打包

**Q**: 项目怎么打包成jar包？

**A**: 使用 Maven 打包：

1. 进入项目目录：
   ```bash
   cd aispring
   ```

2. 执行打包命令：
   ```bash
   mvn clean package -DskipTests
   ```
   - `clean`：清理之前的构建产物
   - `package`：打包项目
   - `-DskipTests`：跳过测试（可选）

3. 打包结果：
   打包完成后，在 `target` 目录下会生成 `ai-tutor-1.0.0.jar` 文件

4. 运行 Jar 包：
   ```bash
   java -jar target/ai-tutor-1.0.0.jar
   ```

## 缓存穿透处理方法

**Q**: 如果缓存穿透，你的处理方法是什么？

**A**: 缓存穿透处理方法：

1. **布隆过滤器**：在缓存之前使用布隆过滤器判断数据是否存在
2. **空值缓存**：对不存在的数据也进行缓存，设置较短的过期时间（如 5 分钟）
3. **请求校验**：在应用层对请求参数进行校验，过滤明显不存在的请求
4. **限流措施**：对同一 IP 的请求进行限流，防止恶意攻击
5. **异步加载**：对于热点数据，采用异步预加载策略

**具体实现**：
- 在 `VocabularyService` 中，对单词查询结果进行缓存，即使结果为空也会进行缓存
- 设置合理的缓存过期时间，避免缓存数据过期导致的频繁穿透
- 实现了 Redis 错误的降级处理，确保系统在 Redis 不可用时仍能正常工作
