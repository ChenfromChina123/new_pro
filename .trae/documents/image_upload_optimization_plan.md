# 图片上传优化与聊天记录加载重构计划

## 问题分析

1. **第二次加载不到聊天记录**：可能是因为消息加载逻辑存在问题，特别是图片消息的处理
2. **只上传图片时出现多余提示**：当用户只上传图片而没有输入文字时，会出现不应该出现的提示
3. **图片上传后输入框中照片不消失**：发送照片后，聊天输入框中的照片应该消失
4. **联网搜索中显示识别结果**：需要隐藏联网搜索中的图片识别结果
5. **第二次加载时图片显示问题**：应该以小照片形式显示在用户气泡中，而不是直接显示识别结果

## 重构计划

### [x] 任务1：修复图片上传后输入框中照片不消失的问题
- **Priority**: P0
- **Depends On**: None
- **Description**: 
  - 确保在调用 `explainImages` 函数时，上传的图片在发送后被正确清除
  - 检查 `clearUploadedImageDraft` 函数的调用时机和实现
- **Success Criteria**: 
  - 发送图片后，聊天输入框中的图片预览消失
- **Test Requirements**: 
  - `programmatic` TR-1.1: 上传图片后点击发送，输入框中的图片预览应立即消失
  - `human-judgement` TR-1.2: 界面整洁，无残留的图片预览

### [x] 任务2：修复第二次加载不到聊天记录的问题
- **Priority**: P0
- **Depends On**: None
- **Description**: 
  - 检查 `fetchSessionMessages` 函数的实现，特别是图片消息的处理
  - 确保消息加载逻辑正确处理包含图片的消息
- **Success Criteria**: 
  - 刷新页面或重新加载会话后，聊天记录能够正确显示
- **Test Requirements**: 
  - `programmatic` TR-2.1: 刷新页面后，之前的聊天记录（包括图片消息）应完整显示
  - `human-judgement` TR-2.2: 聊天记录加载速度正常，无明显延迟

### [x] 任务3：修复只上传图片时出现多余提示的问题
- **Priority**: P1
- **Depends On**: 任务1
- **Description**: 
  - 检查 `explainImages` 函数中处理纯图片消息的逻辑
  - 确保当用户只上传图片时，不会出现多余的提示信息
- **Success Criteria**: 
  - 只上传图片时，消息气泡中只显示图片，不显示额外的提示信息
- **Test Requirements**: 
  - `programmatic` TR-3.1: 只上传图片并发送，消息气泡中应只显示图片
  - `human-judgement` TR-3.2: 界面简洁，无多余的文本提示

### [x] 任务4：优化图片消息的显示逻辑
- **Priority**: P1
- **Depends On**: 任务2
- **Description**: 
  - 确保图片消息在加载和实时显示时都以小照片形式显示在用户气泡中
  - 隐藏用户上传的图片信息和识别结果
- **Success Criteria**: 
  - 图片消息始终以缩略图形式显示，不直接显示识别结果
- **Test Requirements**: 
  - `programmatic` TR-4.1: 发送图片后，消息气泡中显示图片缩略图
  - `programmatic` TR-4.2: 重新加载聊天记录后，图片仍然以缩略图形式显示
  - `human-judgement` TR-4.3: 图片显示大小合适，界面美观

### [x] 任务5：隐藏联网搜索中的图片识别结果
- **Priority**: P1
- **Depends On**: 任务1
- **Description**: 
  - 确保在联网搜索中不显示图片识别结果
  - 检查 `explainImages` 函数中处理搜索查询的逻辑
- **Success Criteria**: 
  - 联网搜索面板中只显示与用户输入相关的搜索结果，不显示图片识别结果
- **Test Requirements**: 
  - `programmatic` TR-5.1: 上传图片并开启联网搜索，搜索面板中不显示图片识别结果
  - `human-judgement` TR-5.2: 搜索结果清晰，无无关内容

## 实施步骤

1. 首先修复图片上传后输入框中照片不消失的问题
2. 然后修复第二次加载不到聊天记录的问题
3. 接着修复只上传图片时出现多余提示的问题
4. 优化图片消息的显示逻辑
5. 最后隐藏联网搜索中的图片识别结果

## 技术要点

- 确保 `clearUploadedImageDraft` 函数在适当的时机被调用
- 检查 `fetchSessionMessages` 函数中对图片消息的处理
- 确保 `explainImages` 函数正确处理纯图片消息
- 优化消息渲染逻辑，确保图片始终以缩略图形式显示
- 确保联网搜索查询不包含图片识别结果

## 预期结果

- 图片上传后输入框中的照片会自动消失
- 聊天记录能够正确加载，包括图片消息
- 只上传图片时不会出现多余的提示信息
- 图片消息始终以小照片形式显示在用户气泡中
- 联网搜索中不显示图片识别结果
